## Perché OpenClaw Manager?

<CardGrid stagger>
  <Card title="Registro istanze" icon="pencil">
    Registra qualsiasi OpenClaw Gateway con URL, token di autenticazione e chiave RSA opzionale.
  </Card>
  <Card title="Sistema di snapshot" icon="add-document">
    Cattura lo stato in un momento preciso e percorri la catena delle versioni — non perdere mai più una configurazione.
  </Card>
  <Card title="Decomposizione configurazione" icon="approve-check">
    Decomponi il JSON del gateway in Minions tipizzati e ricomponilo — senza manipolazione manuale.
  </Card>
  <Card title="Confronto configurazione" icon="setting">
    Confronta due configurazioni o snapshot a livello di campo — vedi subito cosa è cambiato.
  </Card>
