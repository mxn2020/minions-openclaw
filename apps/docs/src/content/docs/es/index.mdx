## ¿Por qué OpenClaw Manager?

<CardGrid stagger>
  <Card title="Registro de instancias" icon="pencil">
    Registra cualquier OpenClaw Gateway con URL, token de autenticación y clave RSA opcional.
  </Card>
  <Card title="Sistema de capturas" icon="add-document">
    Captura el estado en un momento dado y recorre la cadena de versiones — nunca pierdas una configuración.
  </Card>
  <Card title="Descomposición de configuración" icon="approve-check">
    Descompón el JSON del gateway en Minions tipados y recompónlo — sin manipulación manual.
  </Card>
  <Card title="Comparación de configuración" icon="setting">
    Compara dos configuraciones o capturas a nivel de campo — ve al instante qué cambió.
  </Card>
</CardGrid>
