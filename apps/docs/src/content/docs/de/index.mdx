## Warum OpenClaw Manager?

<CardGrid stagger>
  <Card title="Instanzregistrierung" icon="pencil">
    Registrieren Sie jedes OpenClaw Gateway mit URL, Auth-Token und optionalem RSA-Geräteschlüssel.
  </Card>
  <Card title="Snapshot-System" icon="add-document">
    Erfassen Sie den Zustand zu einem bestimmten Zeitpunkt und durchlaufen Sie die Versionskette — verlieren Sie nie wieder eine Konfiguration.
  </Card>
  <Card title="Konfigurationszerlegung" icon="approve-check">
    Zerlegen Sie Gateway-JSON in typisierte Minions und setzen Sie es wieder zusammen — ohne manuelles Eingreifen.
  </Card>
  <Card title="Konfigurationsvergleich" icon="setting">
    Vergleichen Sie zwei beliebige Konfigurationen oder Snapshots auf Feldebene — sehen Sie sofort, was sich geändert hat.
  </Card>
</CardGrid>
