## Pourquoi OpenClaw Manager ?

<CardGrid stagger>
  <Card title="Registre d'instances" icon="pencil">
    Enregistrez n'importe quel OpenClaw Gateway avec une URL, un jeton d'authentification et une clé RSA optionnelle.
  </Card>
  <Card title="Système de snapshots" icon="add-document">
    Capturez l'état à un instant donné et parcourez la chaîne de versions — ne perdez plus jamais une configuration.
  </Card>
  <Card title="Décomposition de configuration" icon="approve-check">
    Décomposez le JSON du gateway en Minions typés et recomposez-le — sans manipulation manuelle.
  </Card>
  <Card title="Comparaison de configuration" icon="setting">
    Comparez deux configurations ou snapshots au niveau des champs — voyez instantanément ce qui a changé.
  </Card>
</CardGrid>
